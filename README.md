# 🌐 JH Innovation Connect

### *Where Jharkhand's Challenges Meet Innovation*

**JH Innovation Connect** is a technology-enabled **Societal Innovation Collaboration Portal** designed to connect **citizens, communities, government departments, Higher Education Institutions (HEIs), universities, industries, startups, MSMEs, CSR organizations, research institutions, and innovation ecosystems** on a single platform.

The platform transforms real-world community problems into opportunities for **research, innovation, entrepreneurship, industrial solutions, prototyping, and implementation**.

---

## 🎯 Vision

> **Identify real problems. Connect the right innovators. Build practical solutions. Create measurable social impact.**

JH Innovation Connect creates a structured digital bridge between people who experience societal challenges and organizations capable of solving them.

Instead of allowing community problems to remain isolated or unresolved, the platform creates a complete journey:

**Problem → Verification → Innovation → Solution → Prototype → Implementation → Impact**

---

# 🏘️ The Problem

Communities across Jharkhand face numerous challenges involving:

* Education
* Healthcare
* Agriculture
* Drinking water
* Sanitation
* Environment
* Energy
* Rural livelihoods
* Accessibility
* Urban infrastructure
* Public services
* Transportation
* Waste management
* Digital services

Citizens are often the first people to identify these problems, but there is no unified mechanism that allows them to systematically submit, track, and collaborate on solutions.

At the same time:

* Universities have academic knowledge and research capabilities.
* Students can develop innovative solutions.
* Faculty can provide technical guidance.
* Industries possess technical expertise and implementation capabilities.
* Startups and MSMEs can build practical products.
* CSR organizations can support funding.
* Government departments can verify challenges and monitor implementation.

The major challenge is the **lack of structured collaboration between these stakeholders**.

JH Innovation Connect addresses this gap.

### Important Workflow Principle

A verified challenge **does not have to go only to a university**.

Both routes can independently solve the same challenge:

```text
                 VERIFIED CHALLENGE
                        │
              ┌─────────┴─────────┐
              ▼                   ▼
         UNIVERSITY           INDUSTRY
              │                   │
              ▼                   ▼
          SOLUTION             SOLUTION
```

This allows the platform to support both **academic innovation** and **industry-driven innovation**.

# 🚀 Installation

## 1. Clone the repository

```bash
git clone <YOUR_REPOSITORY_URL>
```

## 2. Navigate to the project

```bash
cd JH-Innovation-Connect
```

## 3. Install dependencies

```bash
npm install
```

## 4. Configure environment variables

Create a `.env` file using `.env.example` as the reference.

Example:

```env
SUPABASE_URL=your_supabase_url
SUPABASE_ANON_KEY=your_supabase_key

GEMINI_API_KEY=your_gemini_api_key

SMTP_HOST=your_smtp_host
SMTP_PORT=587
SMTP_USER=your_smtp_user
SMTP_PASSWORD=your_smtp_password
```

**Never commit your real `.env` file or API keys to GitHub.**
